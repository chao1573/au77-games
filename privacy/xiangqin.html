《相亲练习手册》隐私政策

本游戏为计划在 Android 平台发布的离线单机互动剧情游戏。正常游玩无需注册账号、连接互联网或向开发者提供个人资料。下面说明游戏本地存档、第三方服务及用户权利。

一、适用范围

本政策适用于《相亲练习手册》（以下简称“本游戏”）的 Android 版本，由本页面所列实际开发者或运营者提供。AU77 Games（冒险与探索）是游戏品牌名称，不代表已注册的公司主体。

本游戏是一款以预设对话、情境选择、人物关系与剧情推进为核心的单机体验。按照当前发布计划，游戏不提供玩家账号、在线联机、在线 AI 聊天、在线支付或云存档服务。

二、我们收集和使用哪些信息

正常使用游戏时，我们不要求填写或上传姓名、手机号、身份证号、住址、位置、通讯录、照片等个人资料，不会由游戏向我们的服务器自动上传玩家存档或游玩记录。

信息或数据用途保存与获取方式
游戏进度、剧情选择、人物关系状态及设置继续游戏、保存玩家选择与体验进度仅写入玩家设备上的本地应用存储；不由游戏自动上传
玩家自行导出或导入的存档（若该版本提供此功能）本地备份、恢复与迁移进度由玩家在本地操作和保管；不由游戏自动发送给开发者
玩家主动发给客服的信息解答问题、处理隐私或产品反馈仅在玩家主动发送邮件时获取其邮件地址、来信内容与主动附加的材料

本游戏不会通过广告或统计 SDK 对玩家进行行为追踪，不收集广告标识符用于定向投放。玩家在 TapTap 等应用商店的浏览、下载、预约或评论等行为，依对应平台的政策处理，并非由游戏本身收集。

三、本地存档与删除

本游戏将运行所需的剧情进度、人物状态、选项及设置保存在本机应用数据区域，用于下次继续游戏。我们没有可读取这些本地存档的开发者云端账号系统。

玩家可以在游戏提供清除记录功能时使用该功能；也可以在设备系统中清除应用数据或卸载游戏来移除本机存档。卸载或清除可能导致进度丢失。若版本提供导出存档功能，导出到其他位置的备份文件需由玩家自行删除。

如果玩家使用设备自带的系统备份或自行把文件同步到云盘，该行为由设备和相应服务提供商管理，不属于本游戏主动提供的云存档。

四、设备权限

本游戏的计划 Android 正式版本不主动申请摄像头、麦克风、通讯录、定位、短信、通话、相册等敏感权限，正常剧情游玩也不需要授权这些能力。

游戏使用 Android 系统提供的应用私有存储功能保存进度，通常无须向用户申请访问其他应用文件或公共相册的授权。若发布版本的系统权限和此处描述发生变化，我们将在更新前说明所需权限、用途和影响。

五、第三方 SDK 与网络服务

根据当前 Android 发布方案，游戏不接入广告 SDK、数据统计 SDK、第三方登录 SDK、支付 SDK、云存档或在线客服 SDK，也不调用开发者自建服务器收集游戏数据。

本游戏在 TapTap 等应用商店提供展示、预约及下载服务，商店平台自身的账号、页面统计、下载及评论等数据处理由其各自的隐私政策约束。

本政策所在的 AU77 Games 资料网页计划通过 GitHub Pages 等静态网页托管平台提供。访问网页时，托管服务可能因网络连接、安全和运维目的处理 IP 地址及访问日志。网页托管的访问记录与本游戏离线运行时的本地存档不同。 相关平台处理以其公布的隐私说明为准。

六、保存期限与安全

游戏本地存档保留在玩家设备内，直至玩家清除或因设备、系统、卸载等原因删除。开发者无法远程恢复这些本地记录。

玩家主动发送的客服邮件及所附资料仅为回应咨询、解决问题或履行适用法律义务而处理，在实现必要目的后依法删除或按要求保存。我们不会将客服邮件用于广告营销。

请妥善保管自己的设备和主动导出的游戏存档，避免将含有个性化剧情选择的文件分享给不希望接收的人。

七、玩家的权利

玩家可通过本地清除、卸载或删除导出文件等方式管理自己设备上的存档。对于玩家主动发给开发者的邮件和附件，可通过下方联系邮箱依法申请查询、更正或删除；我们会在核实后依法律规定处理。

游戏不提供在线账号，因此没有需要在开发者服务器注销的玩家游戏账号。TapTap 等商店账户由各自平台管理。

八、未成年人保护与适龄提示

适龄提示：建议 16 周岁及以上玩家体验。 本游戏涉及现实人际交往、恋爱沟通、相亲选择及关系变化等情境内容，不建议未满 16 周岁的玩家使用。

16 周岁和 17 周岁的玩家依法仍属于未成年人；未满 18 周岁的玩家建议在父母或其他监护人指导下理解游戏内容并合理安排游戏时间。

本游戏不要求未成年人填写真实姓名、手机号或身份证号来体验离线剧情，不提供游戏内充值、玩家聊天或社交公开发布功能。适龄提示不是对监管义务的替代；如发行渠道或适用法规要求额外的实名、防沉迷或其他措施，我们将依法核实并落实后再发布相应版本。

九、政策更新

如本游戏未来增加账户、联网、广告、统计、支付、云存档或额外权限，我们将先更新隐私政策，并按适用要求在功能启用前履行必要告知及授权程序。不同 AU77 Games 游戏分别适用其独立的隐私政策。
